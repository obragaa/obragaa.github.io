  • Python

Abrir o projeto

Cliente pergunta fora do horário e a resposta demora.

Construí um agente que responde por WhatsApp e pelo site usando os documentos da empresa, marca horário, registra interessados e passa para um humano o que não deve responder sozinho. Cada resposta sai com o custo da conversa medido — auditável, não estimado.

  1. Responde com base nos documentos da própria empresa, buscados no PostgreSQL com pgvector.
  2. Marca horário e registra quem demonstrou interesse.
  3. Passa para um humano o que não deve responder sozinho.
  4. Mede o custo de cada conversa, resposta por resposta.
  • Python
  • FastAPI
  • PostgreSQL + pgvector
  • Redis
  • Docker
  • Claude API
